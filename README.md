# Accessible Rides — Taxi Landing Page

Простой прототип лендинга в стиле Behance для сервиса такси, адаптированного под людей, использующих инвалидные коляски. В проекте реализован акцент на доступность, современный визуальный стиль и удобство использования.

📌 Особенности

Доступная верстка (A11y-режим, улучшенные фокусы, крупные элементы)

Поддержка светлой и тёмной темы

Tailwind CSS через CDN

Адаптивный дизайн

Бронирование напрямую на странице (прототип)

Стеклянные карточки, Behance-style оформление

Локальная логика выбора временных слотов (предполагается в JS)

🗂 Структура

Проект состоит из одного HTML-файла с встроенными стилями:

index.html


JS-функционал (выбор времени, очистка, валидация) предполагается подключить отдельно.

🚀 Запуск

Просто откройте index.html в браузере. Никаких дополнительных зависимостей не требуется.
